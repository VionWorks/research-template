# Methodology

## Study design

Describe the experimental, observational, reproduction, benchmark, or comparative design.

## Data / materials

Document datasets, sources, inclusion criteria, exclusions, preprocessing, and licensing constraints.

## Procedure

Write the procedure precisely enough that another person could reproduce it.

## Metrics / analysis

Define measurements, statistical tests, baselines, and decision criteria before presenting results.

## Environment

Record hardware, software, versions, seeds, and configuration when they can affect the outcome.
